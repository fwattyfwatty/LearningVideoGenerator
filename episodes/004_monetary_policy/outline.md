### Chapter 2: 金融政策の仕組み「金利・量的緩和・波及ルート」（約1.8分 / `layout: default` / 難易度: 重）
- **学習ゴール**: 政策金利の変更が実体経済（融資・投資・為替・物価）へ届く波及メカニズム、判断の目安となるテイラー・ルール、そしてゼロ金利制約下で使われる非伝統的手段（QE/QT・フォワードガイダンス）を理解する。
- **Phase A（伝統的金融政策の波及ルートとテイラー・ルール）**:
  - 中央銀行が直接コントロールするのは、銀行同士が超短期（翌日物など）でお金を貸し借りする**政策金利**。
  - 利上げ → 借入コスト上昇・通貨高 → 消費と設備投資が落ち着き**インフレ抑制**。利下げはその逆で**景気刺激**。
  - 判断基準の代表的な目安として **テイラー・ルール**（$i = r^* + \pi + 0.5(\pi - \pi^*) + 0.5y$：目標物価との差＝インフレギャップと、景気の過熱・冷え込み＝需給ギャップから適正金利を考える枠組み）を直感的に紹介。
- **Phase B（ゼロ金利の壁を超える非伝統的手段：QE / QT・フォワードガイダンス）**:
  - 金利を0%近くまで下げ切っても不況が続くとき、中央銀行は国債などを大量に買い入れて市場へ資金を流す **QE（量的緩和）** や、将来の政策方針を予告して市場の予想を動かす **フォワードガイダンス** を使う。逆に引き締め局面では保有資産を減らす **QT（量的引き締め）** を行う。
  - **ずんだもん**: 「金利を上げ下げするだけじゃなくて、お金の量や『これからどうするかの宣言』まで武器にしているのだ！」
- **図解＆安全領域設計**:
  - Phase A: 左→右の波及パイプラインSVG（政策金利 → 融資/設備投資・為替・資産価格 → 景気＆物価）＋下段にテイラー・ルールの `.dg-math-box`（結合文字不使用）。
  - Phase B（`opacity` 同時切替・空白区間ゼロ）: 左カード「伝統的領域（短期金利操作）」vs 右カード「非伝統的領域（QE/QT バランスシート伸縮バー＋フォワードガイダンス期待誘導ダイアグラム）」。

### Chapter 3: 米国FRB ＆ 欧州ECB「使命と構造の違い」（約2.0分 / `layout: wide` / 難易度: 重）
- **学習ゴール**: 同じ欧米の中央銀行でも、法的使命（デュアル vs シングル）と通貨圏の構造（単一国家 vs 多国籍通貨同盟）の違いによって、政策の意図と難しさが大きく異なることを理解する。
- **Phase A（米国 FRB：デュアル・マンデートと基軸通貨ドルの綱渡り）**:
  - FRB の法的使命は **デュアル・マンデート**（①物価の安定 2% と ②雇用の最大化 の両立）。
  - 2022〜23年の急ピッチな利上げで高インフレを抑え込み、2024〜25年には利下げへ舵を切ったものの、粘着的なインフレとエネルギー高の再燃を受け、2026年秋には再び **3.75〜4.00%** へ引き締めて様子を見る慎重な運営に。
  - 意図：「景気を冷やしすぎて雇用を壊す（ハードランディング）」のを避けつつ、インフレ期待が根付く前に火を消す綱渡り。ドルが世界の基軸通貨であるため、FOMC の決定は世界中の金利と資本移動を左右する。
- **Phase B（欧州 ECB：シングル・マンデートと「1つの金利・20カ国のジレンマ」）**:
  - ECB は歴史的なハイパーインフレの教訓から、**物価の安定（中期2%）を最優先するシングル・マンデート**。
  - 2024〜25年に預金金利を2.0%前後まで引き下げた後、2026年は中東情勢などによるエネルギー高・物価再燃を受けて **2.50%** へ再利上げし、会合ごとにデータを見極める姿勢へ転換。
  - 意図と構造的ジレンマ：財政余力のある国と債務負担の重い国が**単一通貨ユーロ**を共有しているため、画一的な利上げは国債利回り格差（分断＝フラグメンテーション）を広げやすい。TPI（伝達保護措置）などの安全網を備えつつ、物価安定とユーロの結束を守るのが核心。
- **図解＆安全領域設計**（`layout: wide`・下端 `padding-bottom: 48px` で `y < 805` 厳守）:
  - Phase A: 左「FRB デュアル・マンデート天秤SVG（物価安定 2% ⚖ 雇用最大化）」＋右「米国FF金利の軌道イメージSVG（急利上げ → 利下げ → 2026年再調整 3.75〜4.00%）」。
  - Phase B: 左「ECB シングル・マンデート（物価2%最優先）」＋右「1つの政策金利 vs 経済体力・財政が異なる加盟国群（国債スプレッド拡大リスクとTPI安全網）SVG」。

### Chapter 4: 日本・日銀 vs 中国・人民銀行「正反対の意図と独自路線」（約2.2分 / `layout: default` / つむぎカットイン / 難易度: 重）
- **学習ゴール**: 長期デフレから「金利ある世界」へ正常化を進める日本（BOJ）と、不動産不況・デフレ圧力の中で緩和と金融枠組みの近代化を進める中国（PBOC）の対照的な意図を理解する。
- **掛け合い骨子**:
  - **つむぎ（カットイン①）**: 「米欧がインフレと戦ってきた一方で、アジアの2大国は全然違う動きをしているよね。日本は段階的に利上げを続けているのに、中国は緩和寄りを保っているのはどういう意図なの？」
  - **めたん**: まさにここが現在の世界経済で最も対照的なポイントです。
- **Phase A（日本・日銀 BOJ：異次元緩和からの「正常化」と賃金・物価の好循環）**:
  - 長年のデフレ脱却のためマイナス金利や **YCC（長短金利操作）** という異例の緩和を続けた後、2024年にマイナス金利を解除。
  - 賃上げの広がりと2%超の物価定着を背景に、2025〜26年にかけて **0.75% → 1.0% → 1.25%前後**（約30年ぶりの水準）へと段階的に利上げし、国債買入も減額。
  - 意図：「デフレに逆戻りさせない慎重さ」を保ちつつ、実質金利の過度な低さによる円安・輸入物価高を抑え、**中立金利**へ近づける「金利ある世界への正常化」。
- **Phase B（中国・中国人民銀行 PBOC：景気下支えの緩和と金利枠組みの近代化）**:
  - 不動産市場の長期低迷と内需の弱さから**デフレ圧力**に直面しており、米欧日とは逆に**「適度に緩和的」**な方針を維持。基準貸出金利（1年LPR 3.00%、5年超LPR 3.50%）の低水準維持に加え、**RRR（預金準備率）** の調整や重点産業向け再貸出でピンポイントに資金を供給。
  - さらに2026年11月には、日々の主要政策金利の軸を従来の7日物から**翌日物リバースレポ（1.25%）**へ移行し、金利シグナルの効きを高める制度近代化も推進。
  - 意図：「不動産バブル再燃や急激な人民元安・資本流出を防ぎながら、実体経済の底割れを食い止める」精密な舵取り。
  - **ずんだもん**: 「日本は『やっとデフレを抜けて正常化』、中国は『デフレを防ぐため緩和と元防衛を両立』で、立っている場所が真逆なのだ！」
- **図解＆安全領域設計**（つむぎ右上枠 `x: 1572..1888, y: 90..254` 回避：`padding-right: 360px` + 両フェーズ上段 `padding-top: 86px`）:
  - Phase A: 日銀の正常化ロードマップSVG（マイナス金利・YCC → 2024解除 → 2025〜26段階利上げ 1.25%へ）＋「賃上げ↔物価の好循環」ループ（共有 `#dg-ico-loop` 活用）。
  - Phase B: 中国PBOCの二面作戦SVG（景気下支え：低LPR・RRR・構造的融資 ⇄ 制約：人民元安定・資本流出防止）＋翌日物リバースレポへの枠組みシフトカード。

### Chapter 5: つむぎの核心質問「為替・トリレンマと中央銀行の限界」（約2.0分 / `layout: wide` / つむぎカットイン / 難易度: 重）
- **学習ゴール**: 各国の金融政策が金利差と為替を通じて干渉し合う構造（国際金融のトリレンマ）と、現代の中央銀行が直面する3つの限界（供給ショック・財政ドミナンス・タイムラグ）を理解する。
- **掛け合い骨子**:
  - **つむぎ（カットイン①）**: 「各国の意図は分かったけど、アメリカが高金利を維持すると日本や新興国から資金が流れて通貨安になるよね？結局、自国の都合だけでは自由に決められないんじゃない？」
  - **めたん**: その疑問を一言で説明するのが、国際経済学の超重要法則 **「国際金融のトリレンマ」** です。
  - **ずんだもん**: 「3つのうち2つまでしか同時に選べないルールがあるのだ！？」
  - **つむぎ（カットイン②）**: 「さらに言えば、エネルギー高みたいな海外要因のインフレや、国の借金が大きいときに、中央銀行の金利操作だけで本当に全部コントロールできるの？」
- **Phase A（国際金融のトリレンマと金利差・為替の連鎖）**:
  - 「①独立した金融政策」「②自由な資本移動」「③為替相場の安定（固定）」の3つは**同時に2つまでしか両立できない**。
  - 米・日・欧は「①＋②」を選び為替は変動相場に委ねるため、金利差の拡大が資本移動と通貨安（円安等）を通じて国内物価へ跳ね返る。一方、中国は「①＋③（管理変動）」を優先するため、②の資本移動規制を手放さない——という構造的選択の違いを明快に対比。
- **Phase B（現代の中央銀行が直面する3つの限界）**:
  - ① **供給ショック（コストプッシュ型インフレ）**: 戦争・エネルギー高・関税など供給側の要因で物価が上がると、利上げで需要を冷やすだけでは景気悪化と物価高が同時進行（スタグフレーション）するジレンマ。
  - ② **財政ドミナンスのリスク**: 政府債務（国債残高）が巨額化すると、利上げが国の利払い費を押し上げ、中央銀行の独立性が政治的圧力にさらされやすくなる。
  - ③ **効果のタイムラグ**: 利上げ・利下げが実体経済に浸透するまで半年〜1年半ほどかかるため、常に「不確実な予測の中で先読み運転する」難しさが伴う。
