  - **めたん**: それが「基軸通貨」の力です。国際決済・価格の基準・外貨準備という3つの役割を1つの通貨が担うことで、世界中の取引コストが劇的に下がるんです。

### Chapter 2: 歴史の法則「ギルダーからポンド、そしてドルへの交代」（約1.8分 / `layout: default` / 難易度: 重）
- **学習ゴール**: 過去400年の基軸通貨の変遷（オランダ・ギルダー → 英ポンド → 米ドル）を通じ、「経済力の逆転から通貨交代まで数十年かかる慣性の法則」と「基軸通貨の4条件」を理解する。
- **Phase A（400年の覇権リレーと「70年のタイムラグ」）**:
  - 17世紀：**オランダ・ギルダー**（東インド会社とアムステルダム銀行が国際金融と海運貿易を掌握）。
  - 19世紀：**英ポンド**（産業革命・大英帝国の海軍力・ロンドンの金融街シティと国際金本位制で「太陽の沈まぬ帝国」の通貨に）。
  - 20世紀：**米ドル**（2度の世界大戦で欧州が疲弊し、世界の金と工業力が米国へ集中。1944年の**ブレトンウッズ協定**で正式に主役交代）。
  - **重要な発見**: 実はアメリカのGDPは**1870年代にはイギリスを抜いていた**のに、ポンドからドルへの完全な交代は1944年（約70年遅れ）でした。通貨覇権には強烈な「慣性」が働き、最終的に大きな戦争や財政危機が引き金になって入れ替わってきたのです。
  - **ずんだもん**: 「国の経済力がトップになっても、すぐには通貨の王座は入れ替わらないのだ！『みんなが使っている安心感』がそれだけ強いのだね。」
- **Phase B（なぜ交代しにくいのか？：基軸通貨を支える4条件＋ネットワーク効果）**:
  - ① **経済規模と貿易ネットワーク**（モノとサービスのやり取りの大きさ）
  - ② **深く開かれた金融・国債市場**（いつでも巨額の資金を出し入れできる流動性）
  - ③ **法の支配と制度的信頼**（勝手に資産を没収されにくい透明性と中央銀行の信認）
  - ④ **安全保障とネットワーク効果**（同盟網・軍事力と、「相手も使うから自分も使う」自己強化ループ）
- **図解＆モーション設計**:
  - Phase A: 上段に `dgWidgets.timeline`（4ノード：`17C オランダ・ギルダー` → `19C 英ポンド` → `1944 米ドル誕生` → `2020s 多極化の胎動`、`focusEach: true`）＋下段に「GDP逆転（1870年代）→ 通貨交代（1944年）＝約70年の慣性タイムラグ」バーSVG（`dgMotion.drawPath` で時間軸矢印を描画）。
  - Phase B（`dgMotion.switchPhase` で空白ゼロ同時切替）: 中央に「ネットワーク効果（使うほど便利になる循環）」コアSVG（`#dg-ico-loop` 回転/パルス）を置き、周囲に基軸通貨の4条件カード（`#dg-ico-globe`, `#dg-ico-landmark`, `#dg-ico-scale`, `#dg-ico-shield`）を順次 `focus`/`unfocus` でハイライト。

### Chapter 3: 金本位制の崩壊と「ドルの特権＆ジレンマ」（約2.0分 / `layout: wide` / 難易度: 重）
- **学習ゴール**: ブレトンウッズ体制が「トリフィンのジレンマ」で崩壊したメカニズムと、1971年のニクソン・ショック（金兌換停止）後もドルが基軸通貨として君臨し続けられた「米国債還流ループ」および「法外な特権」を理解する。
- **Phase A（トリフィンのジレンマと1971年ニクソン・ショック）**:
  - 1944年のブレトンウッズ体制では「**1オンス＝35ドル**」でドルと金を固定交換し、各国通貨はドルに連動させた（金・ドル本位制）。
  - しかし経済学者ロバート・トリフィンが1960年に致命的な矛盾を予言——これが **トリフィンのジレンマ** です。
    - 世界経済の成長に合わせてドルを供給し続けるには、米国が国際収支赤字を出し続ける必要がある。
    - すると海外に出回るドル残高が米国の金保有量を上回り、「本当に金と交換できるのか？」と信認が崩れる。
  - ベトナム戦争の戦費拡大やフランスの金交換要求も重なり、1971年にニクソン大統領が金交換停止を宣言（**ニクソン・ショック**）。世界は金の裏付けがない信用貨幣（フィアット）と**変動相場制**の時代へ突入しました。
  - **ずんだもん**: 「金と交換できなくなったら、ドルの信用がガタ落ちして基軸通貨から転落しそうなのに、なんで生き残ったのだ！？」
- **Phase B（金なしでドルが生き残った仕組み：ペトロダラー＆米国債還流と「法外な特権」）**:
  - 答えは「金の代わりになる巨大な受け皿」が機能したからです。
  - ① **ペトロダラーと資源決済**: 1970年代のオイルショック後、産油国（サウジアラビア等）が原油をドル建てで取引し、稼いだドルを米国債や欧米金融市場で運用する構図が定着。
  - ② **米国債という世界最大の安全資産**: 日本・欧州・中国など貿易黒字国が稼いだドルを米国債で保有 → 米国は低金利で資金を調達し続けられる（フランスのジスカールデスタンが呼んだ **「法外な特権（Exorbitant Privilege）」**）。
  - ③ **裏側の代償**: 常にドル需要が強く貿易赤字が膨らみやすいため、国内製造業の空洞化や巨額の財政赤字（双子の赤字）が蓄積し、近年では米国自身からも「基軸通貨の負担が重すぎる」という不満を生む構造になっている。
- **図解＆モーション設計**（`layout: wide`・`.dg-wide-safe` で下端 `y < 805` 厳守）:
  - Phase A: 左「ブレトンウッズ構造図（各国通貨 ⇄ USD ⇄ 金 1oz=$35）」＋右「トリフィンのジレンマ天秤SVG（左皿：世界へのドル供給拡大 ⚖ 右皿：米国の金準備限界 → 1971年断裂 `pulse`）」。
  - Phase B（`dgMotion.switchPhase`）: 上段に `dgWidgets.flowNodes`（`flowDash: true` の連続破線フロー：`世界貿易・原油決済` → `黒字国にドル蓄積` → `米国債・米市場へ還流` → `米国の低金利調達＆消費`）＋下段に2枚対比カード（左：`法外な特権` メリット／右：`双子の赤字・空洞化` 代償）を `focus`/`unfocus` で対比。

### Chapter 4: 挑戦者たちの現在地「ユーロ・円・人民元と『金』の復権」（約2.0分 / `layout: default` / つむぎカットイン / 難易度: 重）
- **学習ゴール**: 日本円・ユーロ・人民元がドルを抜けなかったそれぞれの構造的制約を理解し、2026年現在のデータから「ドル一極からの緩やかな分散」と「金（ゴールド）の復権」の実態を把握する。
- **掛け合い骨子**:
  - **つむぎ（カットイン①）**: 「歴史を見ると100年くらいで主役が入れ替わっているんだよね？ なら戦後の日本円や、ヨーロッパのユーロ、巨大経済になった中国の人民元が、どうしてドルに取って代われなかったの？」
  - **めたん**: それぞれの通貨が、第2章で見た「基軸通貨の4条件」のどこかで決定的な壁にぶつかっているからなんです。
- **Phase A（3つの挑戦者が越えられない構造の壁）**:
  - **日本円（1980年代〜）**: 1985年のプラザ合意後に急速な円高と世界第2位の経済大国化が進んだが、バブル崩壊と長期低迷・金融市場の開放遅れで国際化が伸び悩み（現在：外貨準備 5.0%・FX取引 16.8%・SWIFT決済 3.7%）。
  - **ユーロ（1999年誕生）**: 外貨準備 **20.6%**・SWIFT決済 **21.9%** を誇る最大の対抗馬。しかし「通貨は1つ・財政と国債は20カ国バラバラ」（Ep004ともリンク）のため、米国債に匹敵する超巨大な単一安全資産を欠く。
  - **人民元（2010年代〜）**: 貿易大国として二国間決済は急増しFX取引シェアは **8.5%**（世界5位）まで伸長。しかし**資本移動規制**（海外へ自由に持ち出せない制約）と司法・政策の透明性への懸念から、外貨準備は **2.1%**・SWIFT決済は **3.1%** にとどまる。
  - **ずんだもん**: 「経済が大きいだけじゃダメで、ユーロは『財政がバラバラ』、人民元は『お金の出入りが自由じゃない』っていう弱点があるのだ！」
- **Phase B（2026年データで見る「静かな分散」とゴールドの復権）**:

  - 注目すべきは「減ったドルが人民元へ丸ごと移ったわけではない」点：
    - 通貨面では豪ドル・カナダドル・スイスフラン・韓国ウォン等の**非伝統的通貨への分散**が進行。
    - さらに外貨準備（COFER）の外側で、各国中央銀行が2022年以降**年約1,000トン規模**で**金（ゴールド）**を大量購入。金価格高騰も重なり、世界の公的準備資産全体で見ると**金がユーロを抜いてドルに次ぐ第2位の準備資産**へ浮上した（WGC）。

### Chapter 5: つむぎの核心質問「『脱ドル』とデジタル決済網は覇権を覆すか？」（約2.2分 / `layout: wide` / つむぎカットイン / 難易度: 重）
- **学習ゴール**: 金融制裁を契機とした非ドル決済網の複線化（CIPS・mBridge・BRICS Pay）の実像と限界を押さえつつ、米国が「ドル連動ステーブルコイン（GENIUS法）」でデジタル時代のドル需要を再強化している最新構図まで含めて、今後の現実解（急交代なき多極併存）を立体的に理解する。
- **掛け合い骨子**:
  - **つむぎ（カットイン①）**: 「ちょっと待って。2022年のロシアに対するSWIFT排除や外貨準備の凍結を見て、新興国が『ドルに頼り切るのは危険だ』って本気で動き出したよね？ CIPSやmBridge、BRICS Payみたいな仕組みが広がったら、今度こそドル覇権が崩れるんじゃない？」
  - **めたん**: まさに今、国際金融のインフラそのものが歴史的な転換点を迎えています。「ドルの武器化（Weaponization）」への警戒から、決済の抜け道＝複線化が急速に進んでいるんです。
  - **つむぎ（カットイン②）**: 「でも決済網が分かれても、代わりに世界全体を受け止められる通貨がないのか……。じゃあデジタル通貨やブロックチェーンの時代になったら、国境を越えて勢力図が変わることはあるの？」
  - **めたん**: 実はここが一番面白い逆転現象が起きているポイントです。デジタル化は「脱ドル」だけでなく、**「新しい形のドル化」**も同時に加速させているんです。
- **Phase A（金融制裁の衝撃と「国際決済網の複線化」）**:
  - 従来の基軸ルート：**SWIFT**（国際送金メッセージ網）＋米国コルレス銀行（**CHIPS**）を通じたドル決済。これが地政学リスク時の制裁レバレッジになることが2022年に可視化された。
  - 広がる3つの代替ルート：
    1. **CIPS**（中国の人民元国際決済システム）：中露・アジア・資源国との二国間貿易で取扱高を拡大。
    2. **mBridge**（複数国ホールセールCBDC基盤）：中国・香港・タイ・UAE等で実取引が拡大し、コルレス銀行を挟まない直接決済を実証（西側は別途 Project Agorá 等で対抗）。
    3. **BRICS Pay**：単一の「BRICS共通通貨」は参加国の経済・利害差が大きく非現実的だが、インドUPI・ブラジルPixなど**各国の国内即時決済網を相互接続**して現地通貨決済を広げる現実路線へシフト。
- **Phase B（なぜ急交代しないのか？：ネットワークの防壁 × 米国ステーブルコインの逆襲）**:
  - **防壁①（媒介通貨としての圧倒的慣性）**: BIS 2025年調査で世界FX取引の **88.4%**、貿易金融の約8割が依然ドル建て。二国間決済は増えても、複数国をまたぐ金融取引ではドルが一番安くて速い。
  - **防壁②（デジタル・ドルの逆襲：ステーブルコイン＆GENIUS法）**:
    - 欧州・中国が公的CBDCを軸にする一方、米国は2025年に連邦法 **GENIUS法** を成立（2027年本格施行予定）させ、民間の**ドル連動ステーブルコイン**（USDT・USDC等、市場規模 約2,700〜3,100億ドル）を制度化。
    - 発行体に**米国短期国債などによる100%裏付け**を義務付けたことで、新興国でデジタル・ドルが使われるほど**米国債への構造的な需要が自動で生まれる**新ループを構築しつつある。
  - **結論**: ドル一極の即時崩壊ではなく、**「ドルを中核としつつ、地域決済網・金・デジタル資産が並走する『多極併存・複線化』の時代」**へ移行している。
  - **ずんだもん**: 「『脱ドル』の動きが進む一方で、デジタルの世界では逆に『ステーブルコイン経由のドル化』まで起きてるのだ！白か黒かじゃなくて、せめぎ合いの時代なのだね。」
- **図解＆モーション設計**（`layout: wide`＋つむぎ回避：`.dg-cutin-head` / `.dg-cutin-body` / `.dg-wide-safe`）:
  - Phase A: テスト版 `ch02_bretton_to_multipolar` Phase B で実証済みの `dgWidgets.flowNodes`（`flowDash: true` 連続破線付き、`#dg-ico-landmark` / `#dg-ico-globe` / `#dg-ico-arrow-lr` / `#dg-ico-zap`）で「SWIFT一極 → CIPS / mBridge / BRICS Pay の複線化」を描画＋下段に3ルートの要約ピル。
  - Phase B（`dgMotion.switchPhase`）: 左右の綱引き・対比レイアウト（左カード：脱ドル・複線化の限界＆FX 88.4%の厚い防壁／右カード：米国 GENIUS 法＆ドル連動ステーブルコイン→短期米国債100%裏付けの新還流ループSVG、`dgMotion.flowDash`＋`focus`/`unfocus`）。
