## 3. 各チャプター詳細プロット ＆ モーショングラフィックス設計

### Chapter 1: 導入「指先のチップに数百億個のスイッチ」（約 1.0分 / `layout: title`）
- **学習ゴール**: 「半導体の微細化＝チップ上の部品を極限まで小さくすること」という直感をつかむ。
- **掛け合い**:
  - **ずんだもん**: 昔のパソコンと今のスマホを比べて「今のスマホの方が小さいのに、なんでゲームも動画もAIもサクサク動くのだ？」
  - **めたん**: 「その秘密が**『半導体の微細化』**です。指先に乗る小さなチップの中に、いまや**数百億個もの電気スイッチ**が詰め込まれているんです」
  - **ずんだもん**: 「数百億個！？日本の人口どころか世界の人口より多いのだ！」
- **HyperFrames 図解＆モーション案**:
  - 画面中央にスマホを配置 → カメラズーム風にSoCチップが拡大 → チップ表面に細かいグリッドが展開し、数字カウンターが `1,000個 (1970年代) → 100万個 → 100億個 → 1,000億個超` と指数関数的にカウントアップ（ムーアの法則のイントロ）。
  - 人間の髪の毛（約70,000〜80,000nm）・ウイルス（約100nm）・先端半導体ノード（2〜3nm）の比較スケールバーがスライド表示。

### Chapter 2: 微細化の基本「トランジスタと3つのご利益」（約 2.0分 / `layout: default`）
- **学習ゴール**: なぜ小さくするだけで性能が上がるのか（スケーリング則 / デナード則の本質）を「電気のスイッチ」の比喩で理解する。
- **掛け合い**:
  - **めたん**: 半導体の基本パーツ「トランジスタ（ON/OFFを切り替える超小型スイッチ）」を紹介。
  - **ずんだもん**: 「スイッチを小さくするだけなら、数が増えるだけじゃないのだ？なんで**速くなったり省エネになったり**するのだ？」
  - **めたん**: 距離が短くなると電子の移動時間が減る（高速化）＆ 狭い領域をON/OFFするだけなので少ない電気で動く（省電力化）と図解で回答。
- **HyperFrames 図解＆モーション案**:
  - 簡易トランジスタ断面図（ソース・ゲート・ドレイン）の模式SVGアニメーション。ゲートに電圧がかかると電子の粒が流れる。
  - **「半分に小さくすると…」ビフォー/アフター比較アニメーション**:
    - 同じ面積の正方形にトランジスタが `1個 → 4個（面積比で4倍密度）` に敷き詰められる。
    - 電子の移動距離（ゲート長）が短くなり、パルス波形の切り替え速度が2倍速にアニメーション。
    - 「① たくさん積める（高機能・低コスト）」「② 速く動く（高クロック）」「③ 電気を食わない（低消費電力）」の3カードが順番に点灯。

### Chapter 3: 微細化が可能にした世界「スマホ・生成AI・社会インフラ」（約 2.0分 / `layout: wide`）
- **学習ゴール**: 微細化が私たちの生活や最新技術（特にAI）の土台になっていることを具体的に結びつける。
- **掛け合い**:
  - **めたん**: 微細化の3大メリットが組み合わさった結果、何が可能になったかを3分野で紹介。
  - **ずんだもん**: 「AIがこんなに急に賢くなったのも、半導体の微細化のおかげなのだ！？」
  - **めたん**: AIの脳にあたるGPUは数千〜数万の計算コアを並列で動かすため、極限の微細化なしには1つのチップに収まりきらなかったことを解説。
- **HyperFrames 図解＆モーション案**（`layout: wide` で画面広く3カラム〜段階展開）:
  1. **手のひらにスパコン（モバイル革命）**: かつて部屋サイズだった計算機 → 現在のスマホSoC（CPU + GPU + NPUが1チップに統合されるブロック図）。
  2. **生成AI・LLMの爆発**: GPU内の膨大なコア行列が波打つように並列計算するビジュアル ＋ パラメータ数・計算量の爆発カーブグラフ。
  3. **エッジAI・自動運転・医療**: 車載カメラのリアルタイム画像認識ボックス、ウェアラブル医療機器、データセンターの電力効率向上アイコン群。

### Chapter 4: つむぎの鋭い質問「永遠に小さくできるの？物理とコストの壁」（約 1.8分 / `layout: default`）
- **学習ゴール**: 微細化が直面している「物理の壁（量子効果・発熱）」と「経済の壁（製造コスト）」を理解する。
- **掛け合い**:
  - **つむぎ（カットイン①）**: 「ちょっと待って！そんなに小さくし続けたら、いつか**原子のサイズ**にぶつからない？それに作る工場の値段もヤバくない？」
  - **めたん**: 「核心を突きましたね、つむぎさん！実は2つの大きな壁にぶつかっているんです」
  - **ずんだもん**: 「壁をすり抜けちゃうって、幽霊みたいなのだ…！」
- **HyperFrames 図解＆モーション案**:
  - **壁① 物理限界（量子トンネル効果とリーク電流）**:
    - スイッチをOFF（壁でせき止め）にしているはずなのに、壁が薄くなりすぎて（数nm＝原子十数個分）、電子の波が壁をすり抜けて漏れ出すアニメーション（リーク電流＝電池消耗＆発熱！）。
  - **壁② コストの壁（EUV露光とメガファブ）**:
    - 光の波長よりも細い線を焼き付ける難しさ → 極端紫外線（**EUV**）露光装置が登場（1台 数百億円・大型バス数台分の精密機械イメージカード）。
    - 最先端工場1つに**数兆円規模**の投資が必要になり、作れる企業（TSMC・Samsung・Intel・Rapidusなど）が世界でも一握りに絞られている構図図。

### Chapter 5: 将来どうなる？「限界を超える4つの次世代技術」（約 2.2分 / `layout: wide`）
- **学習ゴール**: 微細化は「終わり」ではなく、構造・配線・積み重ね・光の技術へ進化し続ける未来像をつかむ。
- **掛け合い**:
  - **めたん**: 平面で小さくするだけでは限界に近づく中、業界が挑んでいる「4つの突破口」を図解。
  - **つむぎ（カットイン②）**: 「あ、そういえば最近聞く『2nm』って、もう実際に2nmの幅があるわけじゃなくて世代の呼び名なんだよね？」
  - **めたん**: まさにその通りで、現在は「平面の縮小」から「立体・積層・システム全体」の戦いに移っていると補足。
- **HyperFrames 図解＆モーション案**（4ステップの変身アニメーション）:
  1. **トランジスタの立体化（Planar → FinFET → GAA → CFET）**:
     - 平べったい電流の通り道が、ヒレのように立ち上がり（FinFET）、周りを360度ゲートで囲み（GAA：ナノシート）、さらにN型とP型を上下に重ねる（CFET）3D断面ステップ変形！
  2. **裏面電源供給（BSPDN / Backside Power Delivery）**:
     - 今まで表側で信号線と電源線が渋滞していたのが、電源線だけチップの「裏側」へ引っ越して道路渋滞を解消する断面図アニメーション。
  3. **チップレット & 3D積層（パッケージング革命）**:
     - 巨大な1枚岩チップ（高コスト・歩留まり悪）を、機能ごとの小チップに分割してレゴブロックのように高密度接続・垂直積層するアニメーション。
  4. **新材料 & 光電融合（電気から光へ）**:
     - 配線抵抗・発熱の限界を破るため、チップ間やチップ内の通信を「電気信号」から「光信号（シリコンフォトニクス）」へ置き換える未来図（IOWNやCPOのイメージ）。
